unmodified licence is in `LICENSE`. Retain attribution and modification

If distributing compiled plugins, accompany them with the corresponding
source for that exact version and the build files. The GitHub workflow
places a source ZIP beside the compiled `.vcvplugin` in the same artifact.
Share both. Publishing the complete repository and retaining tagged source
releases is recommended; a source link alone is not presented here as a
substitute for the obligations in GPLv2 section 3.

## VCV dependency is separately licensed

GPLv2 does not relicense VCV Rack, the Rack SDK or its third-party libraries.
They are downloaded separately, not bundled in this source repository.
Rack's non-commercial plugin exception permits plugins under other licence
terms when the plugin is distributed **free of charge**. This build is
intended for that free-distribution route. Do not assume this package clears
selling a Rack-linked binary; seek appropriate permissions/licensing advice
first. This dependency restriction is not an added restriction to our GPLv2
source licence.
