# Attribution and modifications

**DEstrOy ThEm my rOBOts** is an unofficial, independently branded VCV Rack
adaptation of the supplied DestroyFX clocked portable-effect project.
It is not an official Destroy FX, VCV or 4ms product and is not endorsed by them.

Original Destroy FX effects and names are associated with **Sophia Poirier
and Tom Murphy 7**. Their project is at <https://destroyfx.org/> and its
source information is at <https://destroyfx.org/source.html>.

The supplied portable project describes its DSP as newly written, informed
by publicly documented behaviour, not sample-identical to the original
desktop effects. That attribution is preserved in
`upstream/ORIGINAL_NOTICE.md`; no claim of an exact original-source port is made.

Modifications dated 2026-09-17 for this release:

- New public display brand, plugin slug and five DTMR-prefixed module slugs.
- New blue-on-white artwork and original custom control graphics.
- New panel-rendering widget and visual control positions.
- Reproducible source/design assets, tests and VCV-only GitHub workflow.

The portable audio algorithms and normalized parameter/input/output order
have not been changed. The old notice's private-use description is retained
only as history; this release is offered for redistribution under GPLv2.

The two image files in `design/` are AI-generated artwork developed in this
conversation. The production header atlas is derived from the approved
concept. Code-composed functional labels, controls and layouts are separate.
The artwork is offered under GPL-2.0-only to the extent copyright applies;
no claim is made that AI-generated material is necessarily copyrightable
or exclusively owned. No third-party font file is redistributed.

No VCV/Grayscale component images are included. All bundled knob, button
and jack graphics were generated specifically for this package.
